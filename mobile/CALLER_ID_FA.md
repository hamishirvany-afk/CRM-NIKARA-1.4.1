# Caller ID آفلاین

Caller ID از Android `CallScreeningService` استفاده می‌کند و شماره‌ها را از cache محلی SharedPreferences می‌خواند. تماس برای lookup شبکه معطل نمی‌شود؛ پاسخ Allow ابتدا ارسال می‌شود و سپس lookup محلی انجام می‌شود.

برای Android 10+ کاربر باید Role مربوط به Caller ID / Call Screening را به برنامه بدهد.

## تماس شماره‌هایی که در Contacts گوشی هستند

Android به طور پیش‌فرض تماس شماره‌های موجود در دفترچه تلفن را به CallScreeningService ثالث نمی‌فرستد، مگر اینکه مجوز `READ_CONTACTS` به برنامه داده شده باشد. نسخه v4 این مجوز را فقط با اقدام کاربر درخواست می‌کند.

همین مجوز امکان «ورود دفترچه تلفن گوشی به CRM» را نیز فراهم می‌کند. خواندن مخاطبین کاملاً local است و داده‌ای ارسال نمی‌شود.
